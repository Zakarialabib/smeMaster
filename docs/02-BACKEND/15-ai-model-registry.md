# AI Model Registry

> Data-driven model definitions with capability metadata and embedding space tracking.
> **Source:** `src/shared/services/ai/modelRegistry.ts`

## Overview

The model registry is a single source of truth for all AI models available in SMEMaster. Each model declares its provider, capabilities, tier, context window, pricing, and — critically — its `embeddingSpaceId` for RAG vector index isolation.

## ModelDefinition Interface

```typescript
interface ModelDefinition {
  /** API model id */
  id: string;
  provider: AiProvider;
  /** Human-readable label for UI */
  label: string;
  tier: ModelTier;
  capabilities: ModelCapabilities;
  contextWindow: number;
  pricing?: { inputPer1M?: number; outputPer1M?: number };
  deprecated?: boolean;
  /**
   * Pinned embedding space — vectors from different spaces are NOT comparable.
   * Models sharing an embeddingSpaceId can share a vector index.
   */
  embeddingSpaceId?: string;
}
```

### ModelCapabilities

```typescript
interface ModelCapabilities {
  text: boolean;
  streaming: boolean;
  vision: boolean;
  jsonMode: boolean;
  toolCalling: boolean;
  embeddings?: { dimensions: number };
  stt?: boolean;
  tts?: boolean;
  realtime?: boolean;
}
```

### ModelTier

```typescript
type ModelTier = 'flagship' | 'balanced' | 'fast' | 'budget';
```

## The embeddingSpaceId Concept

The `embeddingSpaceId` is **critical for RAG correctness**. Vectors generated by different embedding models are **not comparable** — a 384-dim BGE-small vector and a 1536-dim OpenAI vector cannot be searched in the same index.

Each embedding model gets a unique `embeddingSpaceId` that pins it to a specific vector space:

| Model                    | Provider | Dimensions | embeddingSpaceId        |
| ------------------------ | -------- | ---------- | ----------------------- |
| `text-embedding-3-small` | OpenAI   | 1536       | `openai-te3-small-1536` |
| `text-embedding-3-large` | OpenAI   | 3072       | `openai-te3-large-3072` |
| `gemini-embedding-2`     | Gemini   | 768        | `gemini-embed-2-768`    |
| `mistral-embed`          | Mistral  | 1024       | `mistral-embed-1024`    |

Models sharing an `embeddingSpaceId` can share a vector index. Models without an `embeddingSpaceId` are text-only and never participate in RAG.

## Lookup Helpers

### `getModelsForProvider(provider): ModelDefinition[]`

Returns all non-deprecated models for a given provider.

```typescript
const openaiModels = getModelsForProvider('openai');
// → 11 ModelDefinition objects
```

### `getModelById(id): ModelDefinition | undefined`

Finds a model by its API model ID.

```typescript
const model = getModelById('gpt-4.1');
// → { id: "gpt-4.1", provider: "openai", ... }
```

### `getEmbeddingModels(): ModelDefinition[]`

Returns all models that support embeddings.

```typescript
const embedModels = getEmbeddingModels();
// → [text-embedding-3-small, text-embedding-3-large, gemini-embedding-2, mistral-embed]
```

### `getModelsByCapability(cap): ModelDefinition[]`

Filters models by a specific capability.

```typescript
const sttModels = getModelsByCapability('stt');
// → [whisper-1, gpt-4o-transcribe]

const ttsModels = getModelsByCapability('tts');
// → [tts-1, gpt-4o-mini-tts]
```

### `getEmbeddingSpaceId(modelId): string | undefined`

Returns the embedding space ID for a model.

```typescript
getEmbeddingSpaceId('text-embedding-3-small');
// → "openai-te3-small-1536"

getEmbeddingSpaceId('gpt-4.1');
// → undefined (text-only model)
```

### `getEmbeddingDimensions(modelId): number | undefined`

Returns the embedding vector dimensions for a model.

```typescript
getEmbeddingDimensions('text-embedding-3-small');
// → 1536

getEmbeddingDimensions('gpt-4.1');
// → undefined
```

## Adding New Models

1. **Add a `ModelDefinition` entry** to `MODEL_REGISTRY` in `modelRegistry.ts`:

   ```typescript
   {
     id: "my-new-model",
     provider: "openai",
     label: "My New Model",
     tier: "balanced",
     capabilities: { text: true, streaming: true, vision: false, jsonMode: true, toolCalling: true },
     contextWindow: 128_000,
     pricing: { inputPer1M: 1.0, outputPer1M: 3.0 },
   },
   ```

2. **For embedding models**, always set `embeddingSpaceId`:

   ```typescript
   {
     id: "my-embedding-model",
     provider: "openai",
     label: "My Embedding Model",
     tier: "balanced",
     capabilities: { text: false, streaming: false, vision: false, jsonMode: false, toolCalling: false, embeddings: { dimensions: 1536 } },
     contextWindow: 8_191,
     embeddingSpaceId: "my-embed-1536",  // ← unique space ID
   },
   ```

3. **Add to `PROVIDER_MODELS`** in `types.ts` for the settings UI dropdown.

4. **Add i18n keys** for the model label if needed.
